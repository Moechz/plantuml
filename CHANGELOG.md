# Changelog

All notable user-visible changes to the PlantUML Server TOS application package.

## 1.2026.10-1 — 2026-11-15

### Added
- First release. PlantUML Server (`plantuml/plantuml-server:v1.2026.10`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8152 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/plantumldocker/`.
